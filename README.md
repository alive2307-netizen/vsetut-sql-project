# Проект «Разработка витрины и решение ad-hoc задач» — маркетплейс «ВсёТут»

Учебный проект курса Data Science (Яндекс Практикум).  
Цель — подготовить витрину клиентских данных `product_user_features` на основе заказов маркетплейса и решить четыре ad-hoc задачи для первичного анализа пользователей.

## Содержимое репозитория

- `VseTut_project_Aleksandr_Ivaschenko-red.sql` — основной файл проекта:
  - запрос для создания витрины данных `product_user_features`;
  - решения четырёх ad-hoc задач;
  - комментарии с выводами по каждой задаче.

## Что сделано

1. **Витрина данных** — агрегированные характеристики клиентов из трёх самых активных регионов (Москва, Санкт-Петербург, Новосибирская область) по доставленным и отменённым заказам.
2. **Ad-hoc задачи:**
   - сегментация пользователей по количеству заказов;
   - ранжирование пользователей по среднему чеку (топ-15 среди сделавших ≥3 заказов);
   - статистика по регионам;
   - активность пользователей по первому месяцу заказа в 2023 году.

## Инструменты

- PostgreSQL
- DBeaver
- SQL (CTE, оконные функции, агрегации, фильтрация)

## Примечание

Параметры подключения к учебной базе данных в репозиторий не включены.
